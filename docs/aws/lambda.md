### Lambda関数の作成

- "Lambda"サービスを検索
- 関数を作成 をクリック

![](lambda/img_20250302_042159.png)

関数の作成をクリックすると画面に遷移するので、コードを入力し、Deployをクリック。


```py
def lambda_handler(event, context):
    return {
        'statusCode': 200,
        'body': 'Hello, World!'
    }
```
