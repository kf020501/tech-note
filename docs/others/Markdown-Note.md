Markdown All in One (VS Code)
----------------------------------------

### ショートカット

| ショートカット  | 機能           |
| --------------- | -------------- |
| Alt + Shift + F | テーブルの整形 |



### コマンド ```Ctrl + Shift + P``` で開く

- 目次の作成
```
> Markdown All in One: Create Table of Contents
```

- 目次の更新
```
> Markdown: Update Table of Contents
```

- HTML書き出し
```
Markdown: Print current document to HTML
```
